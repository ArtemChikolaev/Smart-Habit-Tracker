# Smart Habit Tracker + AI Coach

Приложение для отслеживания привычек, целей и ведения дневника с встроенным AI-коучем — подсказками, планами и умными рекомендациями.

## Основной функционал

- **BLoC**: календарь, streak'и, умные рекомендации, onboarding
- **БД**: привычки, события выполнения, статистика, миграции
- **API**: синхронизация профиля, «контент дня», AI-ответы
- **Offline-first**: работа без интернета с последующей синхронизацией
- **Уведомления**: push и локальные напоминания, напоминания о streak
- **AI-чат**: встроенный чат через Flutter AI Toolkit с function calling (создание привычек, напоминаний и др.)

## Возможные расширения

Виджеты на домашний экран, интеграции с wearables и health-приложениями.
